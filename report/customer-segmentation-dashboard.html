Executive finding

The data contains a broad base of low-to-moderate customers and a very small, exceptionally valuable group. The strongest tested split is two clusters; it is driven by markedly different purchase frequency and monetary value.

The 2-cluster score is excellent, but the second cluster contains only 11 customers. Treat it as an actionable VIP/high-value segment—not as evidence that the broader customer base has no meaningful subgroups.

k-means experiments

Orange evaluated k = 2–6 with k-means++ initialization, 10 re-runs and a 300-iteration limit. These are the scores exported from the Orange report.

Silhouette score by number of clusters

Model choice

Selected configuration: k = 2

The separation is very strong (0.931), while all larger k values score lower. k=5 (0.614) is the best of the remaining tested solutions, but does not surpass the two-cluster partition.

Use the 2-cluster result for a clear VIP-versus-core-customer story. If the project needs more granular marketing personas, test additional models after a log transformation or robust outlier review.

Customer RFM

Raw data: 525,461 rows. Cleaned transaction data: 504,730 rows, dated 1 Dec 2009 to 9 Dec 2010. RFM includes customers with a non-missing ID and positive Quantity and Price.

RFM definitions

RecencyDays between the analysis date (one day after final valid transaction) and a customer's latest purchase.
FrequencyNumber of unique invoices per customer.
MonetarySum of Revenue, where Revenue = Quantity × Price.

Selected Orange path

CSV File Import → RFM only → RFM Preprocess → k-Means → Silhouette Plot / Scatter Plot

RFM only uses Frequency, Recency and Monetary as model features and keeps Customer ID as meta data. Preprocess applies scaling. The selected k-means path has k=3 displayed, evaluates k=2–6, uses k-means++ with 10 initializations, 300 maximum iterations, and normalization enabled.

Workflow nodes and connections found in the .ows file

Input data is also connected to Data Info, Distributions, Box Plot, Scatter Plot and Correlations. A second experiment branch sends selected columns through Preprocess to k-Means (k=2–8) and into a second Silhouette Plot and Scatter Plot. The primary scatter plot uses Frequency × Monetary, coloured by Cluster; the exploratory scatter plot uses TotalQuantity × Monetary.

Important analytical caveat

A high silhouette score does not automatically make a segment commercially complete. Here, k=2 isolates 11 very high-value customers. The conclusion is robust as a description of strong distance separation, but should be complemented with sensitivity checks (for example, log-transforming Frequency and Monetary) before operational targeting.
